[chl191980/valorant-playbook](https://github.com/chl191980/valorant-playbook/tree/10295be30455109f119d2e80d62184bbf1e7f76f/assets/abilities),
pinned to `10295be30455109f119d2e80d62184bbf1e7f76f`. The upstream agent metadata
identifies each public API source URL and ability slot. `abilities/provenance.json`
records filenames, source paths, names, slot mappings and SHA-256 hashes.
C = Grenade, Q = Ability1, E = Ability2, X = Ultimate; our historical `phoenix`
identity maps to Sage. Icons also appear on disabled character previews; they do
not enable skills that have not been implemented. Images load from this site's
own assets, without runtime calls to the source repository or API.
