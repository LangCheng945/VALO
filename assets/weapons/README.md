# Weapon assets

Derived static gun geometry and Ogg samples from public repository
https://github.com/unkwsr/open-aim at e1e81cf8ea37e5c363d7720c78cb17fedf0edd94.
Vandal/Phantom/Classic/Operator: site/aim-viewmodel/*.json + *.bin;
Odin: site/aim-weapons/odin.json + odin.bin; audio: site/media/{weapon}.*.ogg.
Conversion retains positions, normals and indices, removes arms/animation data,
and repacks float32 positions/normals + uint32 indices. Manifest includes SHA256.
Model axes are +X forward, +Z up. Lightning texture is generated by this project.
These are Riot Games game assets; the source repository's MIT license does not
cover Riot assets. This is an unofficial fan project, not endorsed by Riot Games.
No claim of ownership or a redistribution license is made.

All 18 available firearm meshes are now playable. Remaining aim-weapons geometry is unchanged; previewOnly flags were removed. Gunfire samples for these weapons are copied from site/media at the same pinned commit. The default authored Smite presentation remains; these are original static gun shapes, not the original full first-person rigs, textures or animations. Reference ammunition, rate, reload and damage bands are extracted from BiMsX6Xn.js by tools/export-weapon-catalog.py without executing upstream code. Prices and local controls are configuration. BANDIT/WARDEN are not present in this asset source and remain disabled pending verified models and statistics.

## Original base skins

Vandal (`viewmodel.bin` / `gun.png`), Phantom, Classic and Operator now retain their original gun UVs from the same pinned `site/aim-viewmodel` source. The matching source albedo PNGs are retained as `*.original.png`; UVs are float32 pairs in `*.uv.bin`. Source positions/normals were byte-compared with the existing geometry before extracting UVs. The locally generated Smite mapping is retained for other weapons. This restores base appearance; original skinned reload animation is not yet imported.

All 18 existing firearm meshes now have source UV/albedo coverage. The additional fourteen use `site/aim-weapons` definitions and payloads, with shared textures found under `site/aim-viewmodel` when needed. See `original-skins-provenance.json` for source hashes and per-part texture mapping. `tools/export-original-skins.py <payload-directory>` verifies vertex agreement before producing assets. Multi-texture guns use a tiled atlas (512px per source tile); untextured lens parts retain a neutral dark swatch. This change restores static base materials; it does not import complete gun skeleton/part animation.

Vandal now uses the fixed red Gaia variant from `app/mods/aim-viewmodel` at the same commit, including the static gun mesh, original UV/albedo and source magazine geometry. See `gaia/provenance.json` and `docs/gaia-and-settings-import.md`. Historical default Vandal data is available in Git history. Other firearms retain their original base appearance.

Classic and Operator now also load their source gun skeleton/skin weights and sampled firing clips, plus Operator's separate scope mesh/albedo. This supersedes the static-only limitation above for those gun firing mechanisms. Phoenix arms and reload choreography retain the current adapter. See `../mechanisms/provenance.json` and `../../docs/sniper-training-mechanisms.md`.
