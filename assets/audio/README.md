# Audio provenance

step-01..07.ogg and land-01.ogg: public unkwsr/open-aim repository,
commit e1e81cf8ea37e5c363d7720c78cb17fedf0edd94, site/media/step-*.ogg
and land-01.*.ogg. Its runtime explicitly groups these as step/land sounds.

kill-1..5.wav: rootmapavri/amxmodx-valorant-kill-sounds,
commit 53644e4e5f04e00c8b14457e5b27afebb9a3e9e4, alazul/kill1..5.wav.
The source identifies these as Valorant kill cues. We use the fifth cue once
at five kills, rather than creating a synthesized ACE chord. This is a
third-party extraction; exact parity with the current official game/audio
mix and localized announcer is not verified.
