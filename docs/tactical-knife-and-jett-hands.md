# Tactical knife and dedicated Jett hands

The loadout panel now offers Prime//2.0-style karambit and source Tactical knife cosmetics. The choice persists locally under `valo-melee-v1`; the default remains the existing karambit. Changing the option rebuilds the currently held melee viewmodel. Prices, damage, fire interval and the multiplayer `melee` identifier stay unchanged.

Jett uses the pinned source Jett hand textures/meshes and forearms. Other agents retain the shared Phoenix appearance. Firearms and the authored karambit use normalized wrist mounts, 35-joint hands and source-textured forearm segments. Jett and Phoenix resources are cached independently; disposed roots and stale character loads cannot receive late attachments. The `jett-hands.js` compatibility entry delegates to the same guarded loader.

The Tactical knife retains the 992-vertex / 1,274-triangle source mesh and original UV/albedo. It uses complete first-person arm meshes, with the Phoenix 104-joint or Jett 112-joint bind rig, instead of extending the segmented sleeve adapter. Source knife idle, attack and walk tracks contain all 104 canonical joints. Tracks are mapped by name onto each character; Jett's additional eight corrective joints retain their bind offsets and follow their animated parents. This is an adaptation of the common source knife motion, not a claim that the source contains a separate Jett-specific knife animation set.

The model attaches to `R_WeaponPoint` using the source attachment quaternion. Its stage retains the source camera/view transform and centimetre-to-local scale. The native stage cancels the legacy weapon depth offset. A camera-space shoulder guard keeps open upper-arm ends behind the near plane while compensating the elbow transform to preserve the source wrist/weapon trajectory. This also covers draw and locally adapted inspect motion. Existing draw and inspect motion remain local adaptations. Accepted melee attacks restart the source attack clip, with brief entry/exit blends. Local game damage timing remains authoritative. While the complete arm rig is active the segmented hands are hidden and their animation update is skipped. On swaps, private materials and skeleton textures are disposed; immutable geometry and shared albedos remain cached.

Assets come from `unkwsr/open-aim` at `e1e81cf8ea37e5c363d7720c78cb17fedf0edd94`, `site/aim-viewmodel/{knife.json,knife.bin,knife.gun.png,jett.json,jett.bin,jett.arms.png}` and the existing Phoenix source. Source hashes and processing are recorded under `assets/tactical-knife` and `assets/jett-hands`. `tools/export-tactical-knife.py <knife-directory> <jett-directory>` reproduces complete rigs/tracks; the source texture is copied as `assets/tactical-knife/albedo.png`. `tools/export-phoenix-forearms.py <directory> jett assets/jett-hands/forearms.json` reproduces segmented Jett sleeves for firearms/karambit. Underlying game designs/assets belong to Riot Games; community repository MIT licensing does not establish an asset redistribution license.

Chrome validation checks both appearances, original geometry/attachment, rig sizes, source idle/walk/attack/recovery, shader compilation, preserved karambit, rapid swapping, stale-load cancellation and saved selection after reload. First-person regression covers firearm mounts, magazine/reload behavior, inspect, drawing and scopes; the karambit check measures the index-to-ring attachment through inspect phases. Screenshots check idle and swing poses. These are functional/rendering checks, not hardware performance benchmarks.
