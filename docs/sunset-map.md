# Sunset / 日落之城

Sunset is selectable with `?map=sunset` and in the map picker. It uses the complete source `juliett` scene, embedded meshopt/KTX2 textures, source collision volumes, cover and minimap from open-aim snapshot `807f55721e64ca457d763c64a4a1de7b11e5f3eb`. The source map catalog explicitly labels `juliett` as Sunset; the 1.3 README and Sunset scenarios corroborate it. Asset bytes/hashes and source paths are recorded in `assets/sunset/provenance.json`. No upstream JavaScript executes during import.

The current renderer batches the 6,500 source meshes and uses the same shared collision/BVH infrastructure as other maps. Pawn collision excludes projectile-only volumes. No rope package is needed. Five training positions and five tactical positions are sampled against the actual scene. Attacker spawn is the southern street at source (4,48), around floor 2.05; defender spawn is (0,-43.2), floor 3. Their multiplayer positions match the safe client points after the existing 4/3 scale. Client gravity handles small floor/decal offsets.

Planting footprints are reconstructed from the gold minimap regions and scene-floor evidence, not original Riot gameplay triggers. A uses the stepped footprint x≈34…48, z≈−26…−10 at floor 1. B uses an L footprint x≈−58.1…−38.1, z≈−18…−4 with lower floor 2 and rear steps/floors 3…4. Polygon boundaries are inclusive; the approach notches and underground overlapping floor 0 are excluded. Physical collision and supported-ground checks remain required. The same polygon/height test is shared by the browser and Worker.

Rooms accept Sunset, hosts can switch the whole room while preserving player identity/team, and public matches include it in the existing shared random rotation. Existing clients need a refresh to load the new map catalog. Existing round, weapon, bot and Spike rules are retained. Interactive map door logic and source lightmap/SH lighting are not included; the scene uses the existing game lighting and source static geometry.

Validation: `tests/test_sunset_browser.cjs` loads the real GLB, checks both spawns and training/tactical bot placements, moves the player, renders A/B/mid, plants on both real site floors and navigates A approach, B approach and B stairs using swept bot capsules. Worker rooms/map-change tests exercise real WebSocket peers and calibrated Sunset spawns. Spike tests cover stepped footprints, edges, vertical exclusions and prior maps. Sites preparation copies the same source assets.
