# Ability model source research

Verified on 2026-11-05 (Taipei). These are candidate listings, not imported assets.

The pinned open-aim tree includes the Killjoy device and Jett smoke gesture already used by this game. Its current tree does not provide complete props for every agent. The installed Cypher hat/cage are community recreations from staticaron/CypherAgent, not verified Riot originals.

Listings were returned by Sketchfab search with `downloadable=true`. This is not proof the asset is directly obtainable without an account, includes textures/animations, or is an original Riot model. The download endpoint requires account authorization in this environment. No viewer cache was scraped and no login was bypassed. A listing’s community license does not independently grant rights to Riot designs.

No usable Sage orb or Sova drone download was confirmed in these searches. Prefer verifying geometry, material maps, bone hierarchy and file size before replacing runtime props; do not add an entire character mesh merely to render a small projectile.
