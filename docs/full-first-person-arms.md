# Shared complete first-person arms

All 28 selectable identities use complete source first-person arms when holding any of the 18 firearms, the Tactical knife or the Prime-style karambit. Jett keeps the 112-joint Jett mesh/texture; other identities use the shared 104-joint Phoenix appearance. Segmented wrist/forearm adapters remain an asynchronous loading fallback and serve separate ability presentations; they are hidden and skipped once the complete weapon viewmodel is ready.

`native-weapons.js` reuses the same complete arm geometry, texture caches and camera/shoulder safeguards as the melee viewmodels. Vandal (fixed Gaia), Phantom, Classic, Operator, Ghost, Guardian, Sheriff and Marshal have matching source idle, fire, walk, reload and ADS tracks. Remaining guns use compatible pistol/rifle/sniper profiles, with a weapon-length adjustment for the left support branch. These are pose adaptations, not separate original animation sets for those guns. Gameplay ammunition, reload duration, recoil, damage and prices remain authoritative; reload tracks sample normalized game progress.

Installed source gun geometry/UV/albedo are preserved and remounted at the source weapon attachment bone. The fourteen mirrored aim-weapons models are reflected back into source arm space; original viewmodel-space weapons remain unchanged. Existing muzzle effects and unsupported detachable magazines use an adapter from the previous local coordinates. Gun firing mechanisms remain active. Source gun reload tracks drive matching skinned guns and original external magazines for Vandal, Phantom, Classic and Operator. Ghost/Guardian already contain weighted magazine parts. Gaia additionally shows the source spare magazine during a locally chosen reload visibility interval. Exact handling/reload animation for the ten borrowed-profile guns remains adapted.

Both knife skins use complete arm rigs. The authored karambit keeps its blade extension and two-turn inspect. Its wrist is retargeted to a reverse grip and its ring is anchored to the rendered native index joint; other fingers release during inspect. This is an authored adaptation, not an extracted Prime animation. Camera-space clavicle/shoulder guards preserve wrist/elbow/weapon trajectories while keeping open upper-arm ends behind the camera.

Death spectating uses the same complete firearm and karambit arms and plays shot/walk motion from available events. No new network messages or server changes are required. Cosmetic melee selection remains local; the existing spectator melee appearance remains the Prime-style knife. No new remote reload/inspect synchronization is claimed.

The pinned source is `unkwsr/open-aim` at `e1e81cf8ea37e5c363d7720c78cb17fedf0edd94`. `tools/export-weapon-arm-poses.py <payload-directory>` reads the eight viewmodel JSON/binary pairs (Gaia mod `viewmodel` renamed `vandal`) and exports source arm/gun tracks and magazine parts. Assets/hashes are recorded in `assets/weapon-poses/provenance.json`, with Gaia firing weights recorded under `assets/mechanisms`. Underlying designs/assets belong to Riot Games; community MIT licensing does not establish a redistribution license for game assets. Upstream JavaScript is not executed by the exporter.

Validation: `tests/test_all_native_arms_browser.cjs` renders both appearance families across all firearms, exercises reload/fire/scope transitions, verifies real reload ammunition, switches through all selectable identities, and checks both knives. `VALO_ARM_WEAPONS=vandal,odin` runs a focused source/adapted smoke check. First-person, native knife, karambit and spectator browser checks cover existing controls, swaps, original skins, pointer-based ring attachment, death-camera isolation, cleanup and shaders. Screenshots verify representative hip-fire, ADS and reload poses. Hardware frame-rate claims are not made by these functional checks.
