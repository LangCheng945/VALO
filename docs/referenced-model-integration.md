# Referenced character and ability model integration

The character picker now includes a distinct Phoenix identity (`phoenix-original`, model `phoenix-real`) in the duelist role. The legacy `phoenix` ID remains Sage, so old rooms, saved choices and Sage skills keep their meaning. The Worker advertises `agent-phoenix-1`; clients hide confirmation until a multiplayer server supports it. Phoenix can use weapons, melee, Spike and the imported movement poses. Dedicated Phoenix skills remain disabled and are labelled as unavailable in the picker.

`phoenix-avatar.js` extends a compatibility loader in `agent-avatar-base.js`, copied from the previously committed avatar runtime with fresh metadata import URLs. The separately edited original `agent-avatar.js` is preserved. Phoenix loads a 3.1 MB GLB on demand (source 6.0 MB), with source texture resolution capped at 1024 and its unused idle animation omitted. Geometry/material/skeleton instances are independent; source texture payload is cached. All 117 existing pose-bone names map to the imported rig. Translation units, mirrored quaternion axes, root basis, body orientation and gun mounting scale are converted explicitly. Native body meshes use a pose-following waist clip and cap for first-person visibility.

Sova loads the extracted bow and gauntlet only when the bow or ultimate view is used. The cast view uses complete source first-person arm poses instead of individually positioned finger meshes. The gauntlet follows the left elbow; the bow follows the left hand. Charge changes string and arrow positions within camera clearance. The bow is the source's folded prop, with locally reconstructed charge movement; it does not include an original unfold/draw/release animation set. Gameplay projectile logic and authoritative ability rules are unchanged.

Sage's held orb and thrown slow orb load the extracted sphere with a shader shell for motion/glow. The sphere asset is about 11 KB with cropped atlas textures. Other agents retain their own orb colors. Late prop loads check whether their owner has been disposed before attachment; projectile cleanup cannot resurrect a detached visual. Ground placement and projectile collision remain on the existing rules.

Original author, embedded asset-license declarations, pinned sources and SHA-256 hashes are recorded in `assets/agents/phoenix-native/provenance.json` and `assets/abilities/referenced/provenance.json`. The GLBs preserve source credit. The browser-side material/lighting and charge movement adjustments are trainer reconstructions, not original Riot effects.

Validation includes a real Worker test for all 29 identities, Phoenix reconnect and Sage skill impersonation rejection; real-map browser checks cover Phoenix pose bounds, crouch height, weapon firing, first-person body clipping, rendered outline size, Sage identity preservation, held/thrown orb loading and cleanup, Sova source props and charge movement. Rendered screenshots were inspected for body appearance and camera clearance. The Sites build and existing map/capsule/render-budget regressions also pass.
