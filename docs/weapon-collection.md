# Weapon collection and Jett cast hands

The buy sidebar's existing melee selector now contains six additional source models: Black Market butterfly, orange butterfly, Damascus karambit, Prime axe, crowbar and Silkleaf fan. A collapsible gun collection selector offers yellow RGX Vandal, orange/white Gaia Vandal, BlastX Phantom, Prime Guardian, Singularity Sheriff, Smite Ghost and Araxys/Rogue Operator. New defaults are Black Market butterfly and the corresponding first variant for the five non-Vandal gun families; Vandal retains red Gaia. Local selections persist. Original/base appearances remain available. Cosmetics do not change damage, economy, ammunition or server rules.

Body and gun rigs play synchronized source tracks, including scale tracks for folding butterfly handles and the fan. Melee uses available equip, alternating attacks, right-click heavy and Y inspect. Source inspect durations are respected. Orange butterfly borrows the compatible Black Market equip/montages; crowbar borrows axe montages. Missing gun-specific equips borrow the compatible Vandal/Phantom/Operator base clips. Guns without extracted inspect clips keep the existing generic inspect; complete official skin VFX/finishers/audio are not claimed. Existing game shot/reload sounds remain in use.

Jett Cloudburst now presents the extracted Jett intro/loop/outro hand animation over 0.75 seconds. Other abilities retain their existing presentation. The original projectile, smoke placement and network rules are unchanged. Weapon changes, opening the menu and death cancel the cast; fire can interrupt the recovery after 0.25 seconds. Original gun/knife pose sets and all other agents keep the shared complete Phoenix/Jett arm appearance. Remote/spectator skins and inspect/cast animation synchronization are not added.

Damascus uses a captured flat skin palette rather than canonical local bone tracks. Its source bind mesh and final TRS tracks are preserved; Jett indices map to the corresponding captured palette with helper-joint aliases. Gun parts share the original gun skeleton and retain source groups/material maps. Textures load only for the equipped model, are capped at 2048 pixels per side, and are released on switching instead of accumulating GPU textures. Decoded binary pose/model payloads are cached. This is not a claim of measured hardware frame rate.

Source file hashes, processing and catalog live in `assets/collection`. Jett cast source remains the prior pinned `e1e81cf8ea37e5c363d7720c78cb17fedf0edd94` package. Reproduce using `python tools/export-collection.py <download-directory>` and `python tools/export-jett-cast.py <jett-json> <jett-bin>` (see exporter arguments). These scripts parse data without executing upstream JavaScript. Game designs/assets belong to Riot Games; a community code license does not establish redistribution rights to game assets.

Validation: `node tests/test_collection_browser.cjs` exercises every new skin with both Phoenix/Jett arms, reload/ADS, heavy/alternating attacks, inspect, source cast phases, fire recovery and browser/shader errors. The baseline all-native-arms suite explicitly selects base skins to keep its original geometry assertions. Sites preparation copies the same collection assets and runtime modules.
