# Skin audio, Sunset routes/door, smoke and squad behavior

Collection audio: 56 source WAV/MP3 files from open-aim snapshot `807f55721e64ca457d763c64a4a1de7b11e5f3eb`, under `app/mods/media`. Seven gun families provide fire/kill 1–5 cues; Guardian also supplies reload. Black Market butterfly supplies equip/inspect/light/heavy/recovery, axe supplies equip/three attacks, and fan supplies equip/inspect/two attacks. White Gaia shares orange Gaia audio, orange butterfly shares Black Market and crowbar shares axe. Base red Gaia also uses the same Gaia family. Missing dedicated Smite Ghost/Damascus/other sounds keep the existing game audio. Only the equipped family is fetched/decoded; shot input never waits for a download. Motion audio/recovery cancel on swaps, reload, inspect interruption, menus and death. Kill cues replace prior kill cues and use ACE only on exactly the fifth kill. Weapon sounds for other players remain their existing weapon samples; no remote skin-audio synchronization is claimed.

Sunset has six single-player route presets: A Short, A Tube and B Main, each easy/hard. They keep source player positions/yaw, source target pools, randomized selection of 15 targets (16 for A Tube), and 90-second duration. Positions snap to supported, collision-safe source-map floors, rejecting unusable/overlapping points. Easy targets stay stationary; hard targets react/fire, using adapted local AI and source 4-degree aim error. Clearing the pool ends the route without range respawns; death ends a hard run. Retrying selects another subset. Source temporary workshop boundary blocks, exact source actor looks/crouches and source firing cadence are not reproduced. Source scenario bytes and hashes are retained; `python tools/export-trainer-expansion.py` verifies them and rebuilds catalogs without executing upstream JS.

The Sunset roll-up door uses the source gameplay collision primitive `ABombsite_0_KingdomDoorRollUp`, instance 35. Its source bounds are x≈−14.08746…−13.92268, y≈1.94976…6.16664, z≈−10.09964…−5.91129, then scaled by 4/3. The slatted panel, header, buttons and motor/break feedback are authored recreations. F near either button toggles it. Local game tuning is 400 HP and 1.6-second travel; these values are not claimed as extracted Riot parameters. A gate blocks pawn movement during closure and releases it after standing clearance; closing is refused when a living actor occupies the opening. Source rays hit the animated panel. Breaking removes visual/ray/pawn obstruction, and the next round repairs it. Navigation caches invalidate only when solid state changes, not on every bullet.

`sunset-door-1` is authoritative in the Worker. It validates proximity, active/alive/round/realm status, occupancy, shot origin/cadence and panel intersection. Damage comes from server weapon data, not a client damage amount; hitting the door consumes the shot so a separate player hit cannot shoot through it. Melee strikes have weapon/range/cadence validation. Door state persists in room metadata, arrives in late-join/reconnect welcomes and broadcasts to both teams. Map/match/round resets restore it. Sunset creation was also added to the browser RoomClient map allowlist. Existing source collision and Spike support remain intact.

Smoke: visible radius and bot occlusion now share one timed growth/expiry envelope. Cloudburst has interior/exterior shading; a reusable camera fog adjusts colors/visibility inside Jett, Omen, Clove, Brimstone, Astra and Cypher smoke, including spectator/drone cameras, and restores the prior scene fog/background on exit. Existing poison/nearsight and smoke lifetimes remain in use. These remain authored procedural effects, not a complete imported original particle renderer.

Local tactical bots: stable entry/support/flank assignments split attackers between objectives and spread defenders across map sites. Live human teammates retain the existing breadcrumb-follow behavior. Defuse cover bots search several safe cover candidates and face threats/approaches instead of staring at the Spike. Audible opponent footsteps create short-lived investigation contacts within range; allied sounds and stale/far sounds are ignored, and deafening suppresses hearing. Bots do not gain visual targets through smoke/walls from these sound contacts. Multiplayer rooms still use human players, not server AI.

Validation: all imported audio decodes/plays in Chromium; real input checks fire/reload/inspect/heavy selection and cancellation. Browser checks cover the door's real-map passage/collision, break/reset, smoke interior/exit/shaders, all six safe route pools and clear-to-finish without respawn. Real Worker WebSocket tests cover RoomClient Sunset creation, door range/occupancy, two-peer damage, late join and shot consumption. Unit tests cover smoke lifecycle, squad splits, hearing expiry/deafening, defuse/follow rules. Existing Sunset plant/navigation, rooms/map changes, match and Spike checks remain passing. Functional tests do not establish hardware frame rates.

Underlying game art/audio belong to Riot Games; community code licensing does not establish asset redistribution rights. Source hashes: `assets/trainer-expansion/provenance.json`; door source geometry/collision: `assets/sunset/provenance.json`.
